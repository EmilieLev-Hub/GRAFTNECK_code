# GRAFTNECK_code
source code for GRAFTNECK study



*To prepare vulcano plots (as Figure 3 or Figure S5 from article), you have to run the file "Script_preparation_tab_res_for_vulcano.R" after then you get a csv.file with all numerical results. You need to load this csv.file in the script for creating vulcano plots ("script_vulcano_plot_Fig3_article.R" and "script_vulcano_plot_FigS5_article.R")


*To obtain results from IHC data, you have 2 script files : 1) for plotting boxplots and pairwise comparisons for CD8 and CD20 as Figure S2 : "script_IHC_FigS2.R"
2) for results about PDL1/CD3/CD8 and CD20 over multiple comparisons as Figure 2 and Figure S4 : "script_IHC_Fig2_FigS4.R"

*Calculation and results for comparison over the six predefined functional pathways defined in the article, you have to consider the following script (to produce a table like Table 3 from article) : "script_scores_table3.R"

*A csv.file 'Example_data.csv' has been producted in order to understand how it has to be edited for scripts over preparation results table and for calculation over the six predefined pathways scores.
