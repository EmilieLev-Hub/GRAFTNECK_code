# GRAFTNECK_code
source code for GRAFTNECK study



To prepare vulcano plots (as Figure 3 or Figure S5 from article), you have to run the file "Script_preparation_tab_res_for_vulcano.R" after then you get a csv.file with all numerical results. This is that csv.file we need to load in the script for creating vulcano plots ("script_vulcano_plot_Fig3_article.R" and "script_vulcano_plot_FigS5_article.R")
